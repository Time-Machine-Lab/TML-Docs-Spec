name: Team_Resources_Spec
description: 这是一个用于动态管理各种团队资源（如账号、服务器、中间件等）的“元模板 (Meta-Template)”。它没有固定的大纲，完全由用户提供的数据类型驱动生成。
methodology: 
  - "数据驱动生成 (Data-Driven Generation): 文档标题和内部的大纲结构，必须根据用户输入的内容动态生成。例如用户输入社交账号，标题就是《团队社交账号资源》；输入服务器，就是《团队基础设施资源》。"
  - "表格化管理 (Table-Driven): 每一种独立类型的资源，都必须被归纳到一个独立的 Markdown 表格中，方便后期通过脚本或 Agent 进行结构化解析。"
  - "渐进式扩展 (Progressive Expansion): 这是一个活的文档。当用户在后续对话中提供新类型的资源（如中间件）时，Agent 必须能够在文档末尾平滑地追加新的二级大纲和表格，而不是覆盖原有内容。"
out_of_scope:
  - 绝对不要在此文档中进行任何“架构设计”或“技术选型推导”。
  - 虽然是记录账号，但**强烈建议对极其敏感的密码进行脱敏处理**（例如：用 `[已存储于 1Password]` 替代明文），除非用户明确强制要求写入明文。
