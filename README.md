# TML-Docs-Spec (团队文档规范中心)

本项目是 Multi-Agent 协作与人类团队协同的**文档契约库**。

## 🤖 供 Agent 阅读的指南

当你被要求撰写或审查某类文档时，请遵循以下工作流：

1. **寻找契约**：首先读取 `contract/` 目录，找到与你任务对应的 Markdown 模板文件（例如 `contract/需求文档模板.md`）。
2. **阅读指令**：仔细阅读模板顶部的 `[Agent 编写指令]` 和 `边界限制 (Out of Scope)`。**严禁越界输出属于其他文档的内容**。
3. **输出生成**：严格按照模板中的 `#` 标题大纲生成你的文档内容，替换掉 `[]` 括号内的占位符说明。
4. **验证**：生成完毕后，自我核对一遍：你的输出是否遗漏了某个大纲？是否包含了不该包含的内容？
